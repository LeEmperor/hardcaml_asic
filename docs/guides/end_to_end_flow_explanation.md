# Initial Description

The RTL describes how the circuit behaves, but there are a bunch of additional things that go ultimately into a CHIP.


1. Where are the outputs in the physical space of the chip?
2. What manufacturing process is being used to make the chip?
3. How much silicon area do we have to work with?
4. How fast will the circuit run?
5. What resources/primitives are available to implement the RTL?
